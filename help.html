TaxMate UK help

TaxMate keeps income, expense, mileage and receipt records and provides planning estimates. It is not tax advice, an official filing, or affiliated with HMRC.

Making Tax Digital

TaxMate does not submit MTD updates. If MTD applies, use software that HMRC lists for MTD submission and verify the current requirements directly with HMRC.

Backups

Use Back up data in Settings. A JSON export contains app records but no receipt-image binaries. A full ZIP backup includes available receipt binaries and a manifest.

Account deletion

For a signed-in account, use Delete all my data. Deletion is complete only when the app reports server-side success; otherwise contact support so cloud deletion can be retried.
