TaxMate UK help

TaxMate keeps income, expense, mileage and receipt records and provides estimates for planning. It is not tax advice.

Making Tax Digital

TaxMate does not submit MTD updates. If MTD applies to you, use HMRC-compatible software for submission.

Backups

Use Back up data in Settings. JSON backups include a receipt manifest, not image binaries.
